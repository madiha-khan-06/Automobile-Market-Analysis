## 📌 Project Overview

This project analyzes a **car sales dataset** to uncover insights related to pricing, performance, and sales trends.  
It focuses on transforming raw data into meaningful insights using data analysis and visualization techniques.

---

## 🎯 Objectives

- 🧹 Clean and preprocess the dataset  
- 📊 Analyze relationships between key variables  
- 📈 Visualize trends and patterns  
- 💡 Generate actionable insights  

---

## 🔧 Tools & Technologies

- 🐍 Python  
- 📊 Pandas  
- 📈 Matplotlib  
- 🎨 Seaborn  
- 📓 Jupyter Notebook  

---

## 📊 Key Analysis Performed

- 🧹 Handled missing values and cleaned data  
- 🔍 Explored relationships between:
  - 💰 Price  
  - ⚡ Horsepower  
  - 🔧 Engine Size  
  - ⛽ Fuel Efficiency  
- 📈 Created visualizations for better understanding  
- 🏭 Analyzed trends across different manufacturers  
- 📉 Studied price distribution using charts  

---

## 📸 Visualizations Included

- 📊 Bar Charts  
- 📦 Box Plots  
- 🎻 Violin Plots  
- 📉 Histograms  
- 🥧 Pie Charts  
- 🔥 Heatmaps (Correlation Matrix)  

---

## 🚀 Key Insights

- 📌 Strong relationship between engine size and price  
- 📌 Horsepower impacts pricing significantly  
- 📌 Variation in fuel efficiency across cars  
- 📌 Manufacturer-wise sales trends identified
